# Valley of Thought — GitHub Pages

This is a static website (HTML/CSS) and can be hosted free with GitHub Pages.

## Publish it
1. Create a GitHub account at https://github.com/
2. Create a new **public** repository, e.g. `valleyofthought.in`.
3. Upload `index.html` and `style.css`.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main`, folder `/root`, and Save.
6. GitHub will give you a temporary `github.io` address.
7. In GitHub Pages settings, add your custom domain: `valleyofthought.in`.
8. At your domain registrar, add the DNS records GitHub displays.
9. Wait for DNS/HTTPS activation.

## Edit the site
All visible text is in `index.html`. Design is in `style.css`.

Note: the contact email is currently `hello@valleyofthought.in`; change it before publishing if needed.
